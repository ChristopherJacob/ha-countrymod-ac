# Brand assets

## Trademark

The CountryMod name and logo are the property of CountryMod. This project is
not affiliated with, endorsed by, or sponsored by CountryMod or Kingcontech.
The mark is reproduced here only to identify the device this integration
controls, which is the same convention Home Assistant's own
[brands repository](https://github.com/home-assistant/brands) uses for every
manufacturer it supports.

If CountryMod would prefer these assets not be distributed, remove this
directory and drop the brands submission; nothing in the integration depends on
them.

## Files

| File | Size | Use |
| --- | --- | --- |
| `brands/icon.png` | 256×256 | Square mark, transparent — for a `home-assistant/brands` submission |
| `brands/icon@2x.png` | 512×512 | Same, 2x |
| `brands/logo.png` | 512×161 | Wordmark, transparent |
| `brands/logo@2x.png` | 1024×321 | Same, 2x |
| `icon-on-white.png` | 256×256 | Mark on a white rounded square, for dark backgrounds |
| `icon-on-white@2x.png` | 512×512 | Same, 2x |

The square icon uses the burst-and-C mark rather than the full wordmark, which
is 3.2:1 and unreadable at icon size.

Brand colour: `#105B9C`.

## These do not change the Home Assistant UI

Home Assistant serves integration icons from `brands.home-assistant.io`, not
from the integration directory. A custom integration cannot ship its own icon,
so Home Assistant will keep showing a default placeholder until the assets are
accepted into [home-assistant/brands](https://github.com/home-assistant/brands).
Until then these are for the repository README and HACS.

## Provenance, and a caveat

Generated by `tools/make_brand_assets.py` from a 447×447 PNG of the CountryMod
wordmark. White was keyed to transparency, the ink normalised to the brand
colour, and the alpha channel put through a contrast curve after resampling so
the thin burst rays survive being upscaled.

**The source was a low-resolution thumbnail.** The artwork within it occupied
only 303×95 px, and the square mark only 64×95, so producing a 512 px icon
meant upscaling roughly 3x. The results are clean enough for a README or HACS
listing, but they are reconstructed rather than original artwork.

Before submitting to `home-assistant/brands`, ask CountryMod for the original
vector or a high-resolution PNG and re-run the script against that. The script
takes any source with the same layout:

```bash
python3 tools/make_brand_assets.py <source.png> <output-dir>
```

The crop boxes at the top of the script are tuned to the current source and
will need adjusting for a different one.
